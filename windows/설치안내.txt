================================================================
 ClaudeUsageBar (CUBR) — 윈도우 설치 안내
 작업표시줄 트레이에 Claude 사용량(5시간/주간 %)을 실시간 표시
================================================================

■ 폴더 구성
  CUBR-Install.bat      설치 (더블클릭)
  CUBR-Uninstall.bat    삭제 (더블클릭)
  CUBR-Installer.ps1    설치/삭제 실제 스크립트
  ClaudeUsageTray.ps1   트레이 앱 본체
  ClaudeUsageTray.vbs   창 없이 실행해주는 런처
  설치안내.txt          이 문서


----------------------------------------------------------------
 1단계. Claude Code 설치 + 로그인 (인증) — 최초 1회
----------------------------------------------------------------
이 앱은 Claude Code가 로그인 때 저장하는 토큰을 읽어서 동작합니다.
따라서 이 PC에 Claude Code가 설치되어 있고 로그인이 되어 있어야 합니다.
(Claude Pro/Max 구독 계정 필요)

(1) PowerShell 열기
    - 윈도우 키 → "powershell" 입력 → Enter

(2) Claude Code 설치 (이미 설치했다면 건너뜀)
    아래 한 줄을 붙여넣고 Enter:

    irm https://claude.ai/install.ps1 | iex

    설치 후 PowerShell 창을 닫았다가 새로 열어주세요.

(3) 로그인 (인증)
    claude auth login

    → 브라우저가 열리면 Claude 계정으로 로그인하고 승인을 누릅니다.

(4) 로그인 확인
    claude auth status

    → "loggedIn": true 가 나오면 성공.
    이때 토큰이 %USERPROFILE%\.claude\.credentials.json 에 저장되며,
    트레이 앱은 이 파일을 읽습니다. (토큰이 PC 밖으로 나가지 않음)


----------------------------------------------------------------
 2단계. 트레이 앱 설치
----------------------------------------------------------------
(0) 압축을 풀기 전에! (차단 예방)
    다운로드한 zip 파일을 우클릭 → [속성] → 하단의
    [차단 해제] 체크 → [확인] → 그 다음 압축 풀기.
    ("인터넷에서 받은 파일" 표식을 지워 보안 차단을 예방합니다)

(1) CUBR-Install.bat 더블클릭

    ※ "Windows의 PC 보호" (SmartScreen) 경고가 뜨면:
       [추가 정보] 클릭 → [실행] 클릭
    ※ "스마트 앱 컨트롤이 차단했습니다"가 뜨면:
       아래 [문제 해결]의 '스마트 앱 컨트롤' 항목 참고

(2) 설치되면 자동으로 하는 일:
    - %LOCALAPPDATA%\ClaudeUsageBar 에 파일 복사
    - 시작 프로그램 등록 (PC 켜면 자동 실행)
    - 윈도우 [설정 > 앱 > 설치된 앱] 목록에 등록 (여기서 제거 가능)
    - 트레이 앱 즉시 실행

(3) 확인
    - 작업표시줄 오른쪽 트레이에 % 숫자 아이콘이 생깁니다.
      (초록: 여유 / 노랑: 50%↑ / 빨강: 80%↑)
    - 안 보이면 트레이의 숨김 아이콘(^)을 펼쳐보세요.
      항상 보이게 하려면 아이콘을 작업표시줄 쪽으로 드래그.
    - 마우스를 올리면 툴팁, 우클릭하면 5시간/주간 상세와
      리셋 시각, [지금 갱신], [종료] 메뉴가 나옵니다.
    - 1분마다 자동 갱신됩니다.


----------------------------------------------------------------
 삭제 (언인스톨)
----------------------------------------------------------------
둘 중 편한 방법으로:

  방법 A) 윈도우 [설정 > 앱 > 설치된 앱]에서
          "ClaudeUsageBar" 찾아 [제거]

  방법 B) CUBR-Uninstall.bat 더블클릭

어느 쪽이든 실행 중인 앱 종료, 파일, 시작 프로그램, 등록 정보가
모두 정리됩니다. Claude Code 로그인 정보는 앱 것이 아니므로
그대로 유지됩니다.

■ 재설치: CUBR-Install.bat 을 다시 더블클릭 (덮어씀)


----------------------------------------------------------------
 문제 해결
----------------------------------------------------------------
● "스마트 앱 컨트롤에서 이 앱을 차단했습니다"
  → 관리자 권한 문제가 아닙니다. (이 앱은 관리자 권한이 필요 없고,
    관리자 권한으로 실행해도 이 차단은 뚫리지 않습니다)
    스마트 앱 컨트롤(SAC)은 윈도우 11 기능으로, 서명 없는
    개인 제작 프로그램/스크립트를 통째로 차단하며
    SmartScreen과 달리 "예외 허용" 버튼이 없습니다.

    [1차 시도] 다운로드 표식 제거 후 재시도
      1. 풀어놓은 폴더 삭제
      2. 다운로드한 zip 파일 우클릭 → [속성] → 하단
         [차단 해제] 체크 → [확인]
      3. 압축을 다시 풀고 CUBR-Install.bat 실행

    [2차, 그래도 막히면] 스마트 앱 컨트롤 끄기
      설정 → 개인 정보 및 보안 → Windows 보안
      → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정 → [끄기]

      !! 주의: SAC는 한 번 끄면 윈도우를 재설치(초기화)하기
         전에는 다시 켤 수 없습니다. 이 PC에서 SAC를 계속
         쓰고 싶다면 끄지 말고 이 앱 설치를 포기하세요.

● 트레이 아이콘이 "!" 로 표시됨, 또는 숫자가 회색으로 바뀜
  → 마우스를 올려 툴팁의 오류 메시지를 확인하세요.
    회색 숫자는 "갱신이 끊겨 옛 값을 보여주는 중"이라는 뜻입니다.
  → 트레이 아이콘 우클릭 → [오류 기록 열기] 를 누르면 지금까지의
    오류가 시간순으로 정리된 메모장이 열립니다. 원인을 물어볼 때
    이 내용을 함께 보내주세요.
    (파일 위치: %LOCALAPPDATA%\ClaudeUsageBar\cubr.log)
    - "자격증명 없음 / accessToken 없음"
      → 1단계의 claude auth login 을 (다시) 실행
    - "토큰 갱신 실패"
      → PowerShell에서 claude auth login 다시 실행

● 더블클릭해도 아무 일도 없음
  → CUBR-Install.bat 을 우클릭 → [관리자 권한 실행]은 필요 없습니다.
    회사 PC 등에서 PowerShell 실행이 정책으로 막힌 경우일 수 있으니
    PowerShell을 열고 아래를 직접 실행해 오류를 확인하세요:

    powershell -ExecutionPolicy Bypass -File "폴더경로\CUBR-Installer.ps1"

● 사용량 %는 어떤 값?
  → Claude Code에서 /usage 로 보는 것과 같은 값입니다.
    5시간 창 / 주간 한도 사용률(%)과 리셋 시각.
    조회는 무료이며 사용량을 소모하지 않습니다.
